## 附：有用的做法和坑

- 地区 key 写入后一定读回验证。
- Ad set 的 start_time 开跑后不能改，排期要在建立时一次设好。
- Creative 发布后文案不能改，要改只能重建。
- 视频上传 API 只在部分账户开放；可以传到开放的账户，再跨账户挂 video_id。
- Drive 大文件用 `drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t`。
- 兴趣 ID 用 `adbot-targeting-search` workflow 查，不要猜。
- 加 Advantage+ audience 时，年龄下限超过 25 会被拒，要改用「年龄建议」。
- 付费成交归因用 `adbot-us-top-ads`（合并名称变体、排除加拿大）或 `adbot-paid-by-ad`（每天 09:00 MYT 自动跑）。
